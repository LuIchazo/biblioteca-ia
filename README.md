# Biblioteca IA

Sistema web de gestión de biblioteca desarrollado como proyecto académico para demostrar:
- ABM de libros
- ABM de lectores
- ABM de préstamos
- Datos almacenados en memoria
- Arquitectura frontend/backend
- Flujo Git casi Gitflow
- Uso de IA generativa y revisión automatizada de código

## Tecnologías
- React + Vite
- JavaScript
- Node.js + Express
- CSS
- Arrays en memoria

## Ejecución

### Backend
```bash
cd backend
npm install
npm run dev
```

El backend queda disponible en http://localhost:3001

### Frontend
En otra terminal:
```bash
cd frontend
npm install
npm run dev
```

El frontend queda disponible en http://localhost:5173

> Los datos son temporales: se pierden al reiniciar el backend.
